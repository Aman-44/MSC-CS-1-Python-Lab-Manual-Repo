## Syllabus Topics Covered

### Unit 1 - Introduction to Python
- Features of Python and writing the first Python program
- Data types, operators, input/output statements, expressions and assignment
- Using IDLE
- Control statements
- Arrays in Python
- String functions

### Unit 2 - Mutable and Immutable Objects in Python, Functions in Python, Class and Objects
- Lists, tuples and dictionaries
- Defining and using functions with return values
- Required, variable-length and keyword arguments
- Classes and objects; basic class structure and `self`
- Constructors
- Instance methods, class methods and static methods
- Method overloading and method overriding
- Class variables and instance variables
- Inner classes

### Unit 3 - Inheritance, Exception Handling, Modules in Python, File Handling, Regular Expressions in Python
- Introduction to inheritance and types of inheritance
- Different types of exceptions
- `try`, `except`, `else` and `finally` blocks
- Creating and importing modules using `import module` and `from module import`
- File handling modes
- Reading files using `read()`, `readline()` and `readlines()`
- Writing files using `write()` and `writelines()`
- Regular expression basics and use of `match()`, `search()`, `findall()` and `sub()`

### Unit 4 - Database Connectivity, Data Frame in Python, Data Visualization
- Database connectivity modules
- Connecting, opening and closing database connections
- Creating cursors and using cursor methods
- Executing SQL commands
- Inserting, updating and deleting records
- Fetching records using `fetchone()`, `fetchmany()` and `fetchall()`
- Creating DataFrames using CSV files, lists and dictionaries
- Basic graphics: line graph, bar graph, histogram and pie chart

### Unit 5 - Python for Cyber Security
- WHOIS lookups for IP addresses or domain names
- DNS information using `dig`
- Email detection using `re`
- Network communication using `socket`
- Hash generation using `hashlib`
- Operating-system interaction using `os`

## Requirements

- Python 3.x
- A Python-compatible IDE or code editor
- MySQL Server for the Unit 4 database practicals
- Required Python packages:
  - `mysql-connector-python`
  - `pandas`
  - `matplotlib`
  - `python-whois`
- The `dig` DNS utility for the DNS practical in Unit 5
- Internet connectivity for WHOIS and DNS lookups

### Install Python Packages

```bash
pip install mysql-connector-python pandas matplotlib python-whois
```

Recommended editors:
- Visual Studio Code
- PyCharm
- IDLE
- Jupyter Notebook

## How to Run

Clone the repository:

```bash
git clone https://github.com/Aman-44/MSC-CS-1-Python-Lab-Manual-Repo.git
```

Open the repository in your preferred code editor, navigate to the required Python file, and run:

```bash
python filename.py
```

For the MySQL programs, make sure the MySQL server is running and update the connection credentials in the code to match your local setup.

For the WHOIS and DNS programs, ensure that the system has internet connectivity. The `dig` command must also be installed and available in the system PATH.
